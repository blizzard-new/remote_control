# Android 螢幕分享端

Android 8.0（API 26）以上的手機或平板可以授權分享畫面，同一個 Wi-Fi 或私人 VPN 上的電腦使用瀏覽器觀看。每次分享都需要 Android 的系統同意。工作階段有獨立的 HTTPS 網址及 24 碼配對碼，可同時供最多 6 個瀏覽器分頁觀看。

## 建置與安裝

用 Android Studio 開啟本目錄，安裝 Android SDK Platform 35，使用 Gradle 8.9、Android Gradle Plugin 8.7.3 和 JDK 17。選取已啟用 USB 偵錯的手機，按 Run 安裝。命令列亦可在本目錄執行：

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

安裝完成後即可拔除 USB，日常分享使用 Wi-Fi 或私人 VPN。

## 用三星鍵盤觸控板操作電腦

1. 在被控制的電腦上啟動桌面分享。使用區網啟動器時，核對電腦顯示的 SHA-256 指紋，將相符的 `trusted-root.crt` 安裝到三星平板的「CA 憑證」。公開可信憑證可直接連線。
2. 在平板 App 的首頁選「連接電腦（鍵盤觸控板模式）」，輸入電腦顯示的 HTTPS **觀看網址**，再輸入連線碼。請在電腦上核准這台裝置操作。此模式使用 Android System WebView，建議保持更新。
3. 將指標移到遠端畫面，試著在長頁面慢慢向上、向下滑，再在寬表格向左右滑。App 會讀取鍵盤觸控板或滑鼠的原生 Android 捲動軸，保留兩軸的小數增量。在連線表單、畫面邊框或僅觀看模式中，捲動交給 WebView 處理。返回鍵可離開連線。

## 在電腦上觀看

1. 將手機與電腦接到同一個允許裝置互連的 IPv4 Wi-Fi。兩地連線可先依下節連上私人 VPN。開啟「遠端螢幕分享」，開始前選擇畫質，再按「選擇分享畫面」。預設的 H.264 模式適合支援 WebCodecs 的桌面瀏覽器；取消勾選即可使用相容模式。在 Android 的原生提示中選擇要展示的內容並同意。在支援的平台上可選擇單一應用程式。
2. 在電腦瀏覽器輸入手機顯示的 **https 網址和埠號**。手機使用 Android Keystore 內的專屬自簽憑證。首次連線時，在瀏覽器的憑證資訊中比對憑證 SHA-256 指紋與手機顯示的完整值，再接受該裝置的憑證。指紋不同時請關閉該網頁。
3. 在電腦頁面輸入手機顯示的配對碼。手機上的配對資訊頁有螢幕擷取保護，在分享整個螢幕時請切換到要展示的 App，電腦便會看到畫面。其他觀看者可以用同一組網址及配對碼加入。
4. 按手機 App 或通知的「停止分享」，或使用系統投放控制項結束。分享結束後，所有觀看連線都會中斷，舊配對碼隨即失效。下一次分享會產生新配對碼。

使用訪客 Wi-Fi 或基地台的「用戶端隔離」時，兩台裝置可能無法互連。如果瀏覽器政策禁止接受裝置自簽憑證，請使用能核對並接受該憑證的受控瀏覽器。

## 透過私人 VPN 跨網路觀看

先將手機與電腦加入可互相路由的私人 VPN，例如團隊既有的 WireGuard 或 Tailscale 網路。在 Android 啟用 VPN 並允許此 App 使用 VPN，再開始分享。手機會顯示 VPN 網址。在遠端電腦上比對憑證並依相同方式配對。VPN 的路由與存取規則必須允許電腦連入手機顯示的 TCP 埠。單純變更出口 IP 的商業 VPN 通常不提供裝置互連。

服務只綁定目前 Wi-Fi 或 VPN 的單一私人 IPv4 位址，可使用 RFC 1918、100.64.0.0/10 或鏈路本地位址。請在 Wi-Fi、VPN 或位址變更後重新開始分享並使用新網址。

## 傳輸與限制

H.264 模式使用 MediaCodec 的輸入 Surface，編碼一次即供所有觀看者共用。畫面依原始長寬比縮放，最高 1920 × 1080（直向為 1080 × 1920），目標 30 fps，編碼器無法使用該尺寸時會嘗試較低解析度。Android 10 以上優先選用硬體編碼器。電腦使用 WebCodecs 解碼，觀看期間關閉分頁即可離開，在手機仍分享時可重新連線。實際幀率取決於畫面更新、裝置編解碼能力及網路頻寬。

相容模式以 JPEG 傳送畫格，依長寬比縮至長邊最多 1280 畫素，目標約 12 fps。遇到不支援 WebCodecs、解碼失敗或手機編碼器失敗時，停止分享，取消勾選 H.264 後重新配對。

兩種模式均使用 Android MediaProjection 和前景服務。畫面旋轉或 Android 改變分享區域時，程式會調整原本的虛擬顯示器。音訊、反向觸控、跨網際網路中繼及 iOS 主機仍未實作。Android 的安全畫面可能顯示為黑色。

配對碼透過 HTTPS 表單傳送，配對成功後由僅限該工作階段的 Secure、HttpOnly Cookie 辨識觀看者。持有當次配對碼即可觀看。可從手機 App 查看觀看數量。要撤回已分享的配對碼，請停止該次分享。

## 在 Android 模擬器驗證

預備英文介面的 Android 13（API 33）AOSP 模擬器，接上模擬器的 AndroidWifi。執行下列指令。測試依序從 App 開啟兩次分享，在系統的螢幕擷取確認對話框按下同意，使用畫面上的憑證指紋與配對碼驗證 HTTPS 連線，讀取 JPEG 與 H.264 串流，並從 App 停止分享。

```sh
adb shell svc wifi enable
./gradlew :app:connectedDebugAndroidTest
```

若只需建置與檢查，執行 `./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug`。
